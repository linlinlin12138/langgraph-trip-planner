# Archived datasets

- `llm_v1/`: 10-sample LLM rewrite trial (claude-sonnet-5-5 rewriter, gpt-6.1-terra checker) made against the
  first catalog (fictional hotels / restaurants, 5 dietary restrictions, catalog commit `6cca624`). Its gold labels use
  restrictions that no longer exist (halal / vegetarian / no_pork), so it does not load with the current schema.
  Kept for the record of the rewrite-quality and back-check experiments only.
